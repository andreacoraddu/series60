# Series 60 CB=0.60 Hull Explorer

Interactive GitHub Pages site for the Series 60 CB=0.60 parent hull.

The published page includes:

- 2D lines-plan plots
- 3D hull views
- experimental self-propulsion tables and plots

Main entry points:

- `index.html`
- `series60_cb060_geometry_m.html`

The site is designed to publish directly from the repository root with GitHub Pages.
